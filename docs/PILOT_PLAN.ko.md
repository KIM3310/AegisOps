# 공공기관 비운영 환경 8주 실증 계획

## 범위

기관 한 곳의 업무, 서비스 한 개, 사건 유형 2~3개, 로그 형식 한 개, 보고서 서식 한 개를 목표로 합니다. 협력기관 확보와 자료 사용 승인은 아직 확인된 실적이 아닙니다.

한 가지 승인된 비운영 환경에서 합성 또는 사용 승인을 받은 로그 사본을 분석합니다. 실시간 운영계 연결, 관리자 명령 실행, 자동 차단·재시작·패치·설정 변경은 포함하지 않습니다. 로컬 데모의 합성 매뉴얼을 기관 승인 매뉴얼로 표시하지 않습니다.

## 시작 전 확인

1. 업무 담당자, 보안·개인정보 담당자, 유지보수업체와 책임 범위를 정합니다.
2. 사용 가능한 데이터 항목, 보존 기간, 접근자, 삭제 방법을 서면으로 확인합니다.
3. 원본 로그, 문서, 프롬프트, 임베딩, 출력, 진단 텔레메트리의 처리 경로를 확인합니다.
4. 외부 LLM이나 클라우드로 전송할 경우 별도의 승인을 확인합니다. 비식별 처리만으로 전송 권한이 생기지 않습니다.
5. 중단 조건과 연락 담당자를 정합니다. 승인되지 않은 정보가 발견되면 입력을 중단합니다.

기관의 승인이나 협력 참여가 지연되면 합성 사례 평가만 진행합니다. 그 결과를 현장 실증, 실제 MTTR 개선, 유료 수요 검증으로 발표하지 않습니다.

## 주차별 산출물

| 기간 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1~2주 | 실무자 5명 인터뷰 목표, 업무·자료·평가 기준 합의 | 인터뷰 기록, 승인 범위, 사건 유형, 수작업 기준 시간 |
| 3~4주 | 단일 입력에서 대응안·기관 서식까지 연결 | 재현 가능한 데모, 고정된 평가 데이터와 채점표 |
| 5~6주 | 보지 않은 사례와 잘못된 입력 평가 | 담당자 검수 결과, 근거 오류, 위험한 단계, 문서 수정량 |
| 7~8주 | 수작업과 비교, 실패 수정, 도입·가격 조건 확인 | 시간·오류·원가 보고서, 실패 목록, 후속 제안서 |

## 평가 방법

- 20~30개 사례를 목표로 준비합니다. 표본 수가 부족하면 그 사실을 보고합니다.
- 개발·매뉴얼 작성에 사용한 사례와 평가 사례를 분리합니다. 평가 답안을 검색 자료에 넣지 않습니다.
- 난이도와 사건 유형을 맞춰 수작업과 AI 보조 조건을 교차 배정합니다. 순서에 따른 학습 효과를 기록합니다.
- 가능한 경우 실무자 두 명이 사전 정의한 기준으로 근거와 절차를 검토합니다.
- 중앙값과 상위 지연값, 개별 실패 사례를 함께 보고합니다. 좋은 사례만 골라 평균을 내지 않습니다.

| 지표 | 제안 목표 | 측정 범위 |
| --- | --- | --- |
| 초기 대응안 작성 시간 | 중앙값 30% 단축 | 알림 확인부터 사람이 사용할 수 있는 검수 완료 초안까지 |
| 보고·인수인계 문서 작성 시간 | 중앙값 50% 단축 | 생성, 검토, 수정, 서식 정리 포함 |
| 근거 정확성 | 사전 합의한 기준 충족 | 출처 존재뿐 아니라 내용·버전·대상 시스템과 절차의 일치 |
| 안전성 | 무승인 변경·반출 불허 | 잘못된 제안, 근거 부족 시 유보, 로그의 명령문을 지시로 따르지 않는지 확인 |
| 원가 | 실측 후 가격 가설 수정 | 사건당 모델비, 기관별 설치 시간, 지원 시간, 저장 비용 |

위 수치는 달성한 성과나 보장값이 아닙니다. 모델 응답이 빠르더라도 담당자 수정 시간이 늘면 개선으로 판정하지 않습니다. 사례 재현 결과와 실제 운영 장애의 복구 시간을 구분합니다.

## 종료와 후속 단계

1. 합의한 형식으로 결과와 실패 사례를 전달합니다.
2. 자료 반환·삭제와 임시 접근권한 회수를 확인합니다.
3. 실제 구매권한자에게 예산, 기존 계약, 지원 조건과 가격 수용성을 확인합니다.
4. 운영계 읽기 전용 연동은 별도 보안검토와 승인 과제로 제안합니다.
5. 공공 SaaS의 보안인증·심사·계약 경로는 기관과 제공 방식에 맞춰 검토합니다.

## 기록 양식

사례마다 다음 항목을 남깁니다. 공개 결과에는 실기관 식별정보와 원본 로그를 포함하지 않습니다.

```text
case_id, scenario_type, synthetic_or_approved, difficulty, evaluation_order,
manual_version, provider_mode, baseline_seconds, assisted_seconds,
review_seconds, citation_errors, unsafe_steps, document_edits,
model_cost_krw, support_minutes, reviewer_notes
```
